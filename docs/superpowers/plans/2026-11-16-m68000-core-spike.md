# Bus-visible M68000 core spike implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Determine whether an ISC-licensed ares-derived M68000 interpreter can become MesenCE's native, traceable Genesis main CPU without importing a second console framework.

**Architecture:** Port only the ares M68000 processor component behind a MesenCE-owned host seam with explicit idle/wait/read/write callbacks and UDS/LDS strobes. Run it on a flat test bus before creating `Core/MD`; compare architectural state and ordered bus transactions against primary documentation and independent SingleStepTests vectors.

**Tech Stack:** C++17, ares M68000 component (ISC), MesenCE serializer/debug types, SingleStepTests/m68000, nlohmann JSON, mise, ASan/UBSan.

**Spec:** [`docs/research/mega-drive-genesis-feasibility.md`](../../research/mega-drive-genesis-feasibility.md)

## Global constraints

- Import no ares Mega Drive system, scheduler, Node, Thread, UI, audio, or video code.
- Record the exact upstream revision and preserve the license/copyright notice for every derived file.
- The host seam exposes byte lanes, function code, transaction ordering, address errors, reset, interrupt acknowledge, prefetch, and cycle advancement.
- No accepted difference may be hidden by an opcode-wide wildcard; every classification names the opcode/case/source.
- SingleStepTests/m68000 is MAME-generated and is not independent proof of MAME behavior; its README caveats for `TAS`, `TRAPV`, and inherited MAME bugs remain visible.
- The spike ends with an explicit adopt/reject decision before `Core/MD` or Z80 extraction begins.
- The provisional performance floor is 20 times the NTSC Genesis 68000 clock on deterministic instruction mixes, with less than 64 MiB peak memory for the flat harness, on both arm64 and x86-64 release builds.

## Review focus

- Odd word/long access: raise the correct address error before committing a bus transaction.
- Upper/lower byte access: preserve UDS/LDS values and data-lane placement in traces.
- Exception during prefetch: stack frame, supervisor transition, and visible reads must remain ordered.
- Self-modifying code: invalidate or replace prefetched words according to the selected model.
- Cycle-budget boundary: never split a transaction into a state that cannot be serialized or resumed deterministically.
